# Python Calculator

A simple command-line calculator built using Python that performs basic arithmetic operations. This project demonstrates the use of functions, conditional statements, loops, and user input handling.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Continuous calculations until the user chooses to exit
* Simple and beginner-friendly implementation

## Technologies Used

* Python 3

## Project Structure

```
calculator.py
README.md
```

## How It Works

1. Enter the first number.
2. Enter the second number.
3. Choose an operation:

   * `+` Addition
   * `-` Subtraction
   * `*` Multiplication
   * `/` Division
4. The calculator displays the result.
5. Choose whether to continue or exit the program.

## Example

```
What's the first number?: 12
What's the second number?: 4
What do you want to do?
+ , -, * or /
/

12 / 4 = 3.0

Do you want to continue?
Type y for yes and n for no:
```

## Getting Started

Clone the repository:

```bash
git clone https://github.com/IshaThakar/python-calculator.git
```

Navigate to the project folder:

```bash
cd python-calculator
```

Run the program:

```bash
python calculator.py
```
