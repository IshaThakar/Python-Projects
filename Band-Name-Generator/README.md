# Band Name Generator 🎸

A beginner-friendly Python project that generates a band name by concatenating two user-provided words.

## Description

This program prompts the user to enter two words (such as a city name and a pet's name) and combines them using string concatenation to create a fun band name.

## Features

- Accepts two user inputs
- Uses string concatenation
- Displays the generated band name

## Example

```text
Welcome to the Band Name Generator!

What's the name of the city you grew up in?
London

What's your pet's name?
Buddy

Your band name could be London Buddy
```

## Technologies Used

- Python 3

## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/band-name-generator.git
   ```

2. Navigate to the project folder:
   ```bash
   cd band-name-generator
   ```

3. Run the program:
   ```bash
   python main.py
   ```
