# Bill Tip Splitter

A simple Python application that calculates the tip amount and evenly splits the total bill among multiple people.

## Features

- Calculate tip based on a custom percentage
- Split the bill among any number of people
- User-friendly command-line interface
- Accurate bill calculations
- Beginner-friendly Python project

## Technologies Used

- Python 3

## How It Works

1. Enter the total bill amount.
2. Enter the desired tip percentage.
3. Enter the number of people sharing the bill.
4. The program calculates:
   - Total bill including tip
   - Amount each person should pay

## Example

```text
Welcome to the Bill Tip Splitter!

Enter the total bill: 2500
Enter tip percentage: 10
Number of people: 5

Each person should pay: ₹550.00
```
